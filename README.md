# 五行 Wu Xing

Roguelike deckbuilder solo, theme cultivation (xianxia). Un paquet de 70 cartes (5 elements x rangs 1 a 14),
des mains a former, des artefacts, des pilules et des manuels de technique pour franchir les royaumes.
Score = Qi x Comprehension. Fait avec Godot 4.7.

## Jouer

- Web : version publiee sur itch.io (a venir avec la v1.0.0).
- Windows : exporter avec `godot --export-release "Windows Desktop"` (presets dans `export_presets.cfg`),
  ou lancer le projet dans Godot 4.7.1.

## Touches

| Action | Touche |
| --- | --- |
| Selectionner une carte | souris, ou 1 a 8 |
| Jouer la main | Entree |
| Defausser | D |
| Deselectionner | Retour arriere ou clic droit |
| Trier par rang / par element | R / E |
| Voir le paquet | Tab |
| Voir le parcours | V |
| Vendre un artefact | S |
